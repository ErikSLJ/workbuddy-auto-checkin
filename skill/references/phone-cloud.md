# 纯手机用户 / 无常开设备：云函数定时签到方案

> 适用：用户没有 24 小时不关的电脑，也没有软路由，只有手机。
> 思路：把签到逻辑部署到云平台（腾讯云 SCF 等）的「云函数」，由云平台的定时器
> 每天触发，实现"没有设备也能自动签到"。手机只用来一次性配置，之后全自动。

## 为什么手机自己跑不了

手机（iOS / Android）无法稳定运行 Python 定时脚本，也没有常驻执行环境。
因此必须把"执行体"放到云端：云端函数 + 定时触发器 = 代替电脑定时任务。

## 方案总览（腾讯云 SCF，免费额度足够个人用）

1. 在一台**任意**电脑上（朋友/公司都行，只需这一次）获取你的长效令牌。
2. 在腾讯云创建一个 Python 云函数，上传部署包，填入令牌，建定时器。
3. 之后每天 09:00 云端自动签到 + 派猫猫旅行，与你用什么手机无关。

## 步骤 1：获取长效令牌（只需一次，在任何电脑上）

让用户在**已登录 WorkBuddy 的电脑**上执行（可用本技能随附脚本）：

```bash
python <技能目录>/scripts/rt_auth.py --export-rt
```

终端会打印出一整段很长的令牌（形似 `eyJ...` 的三段式）。
把它复制保存好——这就是要填进云函数的 `WB_RT`。

> 如果用户自己没有电脑，可让他在手机浏览器登录 WorkBuddy 网页版后，
> 用"网页会话授权通道"（见 SKILL.md 通道 B）导出；或直接请有电脑的朋友代跑
> 这一步（令牌等同账号钥匙，仅本人保管，勿外泄）。

## 步骤 2：创建云函数

1. 打开腾讯云「云函数 SCF」控制台（https://console.cloud.tencent.com/scf），登录。
2. 新建函数 → 选择「空白函数」→ 运行环境 **Python 3.10**。
3. 函数名称随意，例如 `workbuddy-checkin`。
4. 在「函数代码」处：把本参考同级目录 `assets/cloud_function/main.py`
   与同技能的 `scripts/rt_auth.py`、`scripts/workbuddy_checkin.py`、
   `scripts/push_message.py` **四个文件打包成 zip** 上传
   （SCF 上传 zip 后会自动解包到函数根目录，main.py 在根即可）。
   - 执行方法填：`main.main_handler`
5. 在「环境变量」里新增：
   - `WB_RT` = 步骤 1 拿到的那段长效令牌
6. 在「触发方式」里新增**定时触发器**：
   - 触发周期选「自定义」→ 填写 `0 9 * * *`（北京时间每天 09:00）
   - 或选「每天」+ 09:00。
7. **绑定 CAM 角色**（关键，否则令牌轮换后云上会失效）：
   - 函数配置 → 角色 → 新建/绑定一个角色，给该角色
     `QcloudSCFFullAccess`（或至少 `scf:UpdateFunctionConfiguration`）。
   - SCF 运行时会自动注入 `TENCENTCLOUD_SECRET_ID / TENCENTCLOUD_SECRET_KEY`，
     供 `main.py` 把轮换后的新令牌回写环境变量 `WB_RT`。

## 步骤 3：测试一次

在函数控制台点「测试」，触发 `main_handler`。查看日志：
- 出现 `status=ok` 且 `msg` 含"领取成功/今日已签到" → 成功。
- 出现 `need_setup` → `WB_RT` 没填或填错，回到步骤 1/2。
- 出现 `[persist] WB_RT 已回写` → 令牌自续已生效，之后无需人工干预。

## 注意事项

- 令牌长效但**每次刷新会轮换**（旧令牌作废）。云函数已做"回写环境变量"自续，
  前提是第 7 步的 CAM 角色权限已配置；未配置则实例冷启动后可能需重设 `WB_RT`
  （日志会提示），属可接受的运维边界。
- 免费额度：SCF 每月有免费调用次数与资源用量，个人每日 1 次签到远低于阈值。
- 想换时间：改定时触发器的 cron 即可。
- 想停止：删掉定时器触发，或删除函数。
- 隐私：令牌仅存于你自己的云函数环境变量，不进任何第三方仓库；
  云厂商不会读取你的函数代码内容。

## 其他云平台（可选）

逻辑完全一样，把 `main.py` 作为入口、带上三个依赖脚本即可：
- **阿里云函数计算 FC**（Python runtime，定时触发器用 Cron 表达式）
- **Cloudflare Workers**（需改写为 JS，本技能未提供，可参照同样 HTTP 接口实现）
- 任意支持 Python + Timer 的 Serverless 平台
